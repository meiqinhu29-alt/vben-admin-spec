# 日报系统 · 使用说明

## 系统概述

日报系统用于管理店铺每日资金流水，支持多店铺、多角色协作。核心流程：员工/店长录入日报 → 财务审核 → 老板锁定确认。

访问地址：`http://101.200.219.28`

## 账号与角色

| 角色 | 默认账号 | 密码 | 可见模块 | 数据范围 |
|------|----------|------|----------|----------|
| 系统管理员 | admin | admin123 | 资金管理 + 系统管理 | 全部数据 |
| 老板 | boss | admin123 | 资金管理 | 所属店铺 |
| 财务 | finance | admin123 | 资金管理 | 所属店铺 |
| 店长 | manager | admin123 | 资金管理 | 所属店铺 |
| 员工 | staff | admin123 | 资金管理 | 仅自己创建 |

> 首次登录后请立即修改密码。

## 一、资金日报

### 1.1 日报列表

登录后进入「资金管理 → 资金日报」，可看到日报列表。

**筛选条件：**
- 店铺（下拉选择）
- 状态：未审 / 已审 / 锁定
- 日期范围

**列表顶部统计卡片：**
- 营业额、实际业绩、刷给公司、店铺费用、期末余额

### 1.2 创建日报

点击「新建」按钮，填写以下字段：

| 字段 | 说明 | 必填 |
|------|------|------|
| 店铺 | 选择所属店铺 | 是 |
| 日期 | 报告日期 | 是 |
| 期初余额 | 自动带入上一日期末余额 | 自动 |
| 营业额 | 当日营业总额 | 是 |
| 卡扣 | 刷卡手续费等扣款 | 否 |
| 刷给公司 | 刷卡转入公司账户金额 | 否 |
| 转/存公司 | 转账或存入公司金额 | 否 |
| 店铺费用 | 店铺日常开支 | 否 |
| 交给老板款 | 交给老板的现金 | 否 |
| 充值收入 | 会员充值等收入 | 否 |
| 商场结算 | 商场结算款项 | 否 |
| 其他公司收入 | 其他来源收入 | 否 |
| 公司转老板 | 公司转给老板的款项 | 否 |
| 刷卡支付 | 刷卡支付金额 | 否 |
| 公司奖金 | 公司发放的奖金 | 否 |
| 附件 | 支持上传凭证图片 | 否 |

**自动计算字段：**
- 实际业绩 = 营业额 - 卡扣
- 期末余额 = 期初余额 + 实际业绩 - 刷给公司 - 转/存公司 - 店铺费用 - 交给老板款

### 1.3 日报状态流转

```
创建 → 未审(pending) → 已审(audited) → 锁定(locked)
                ↑              │
                └── 反审 ──────┘
```

| 操作 | 说明 | 谁能操作 |
|------|------|----------|
| 创建 | 新建一条日报 | 员工、店长、财务 |
| 编辑 | 修改未审状态的日报 | 员工、店长、财务 |
| 删除 | 删除未审状态的日报 | 店长、财务 |
| 审核 | 未审 → 已审，确认数据无误 | 财务 |
| 反审 | 已审 → 未审，退回修改 | 财务 |
| 锁定 | 已审 → 锁定，最终确认 | 老板 |
| 解锁 | 锁定 → 已审，解除锁定 | 老板 |

> 锁定后的日报不可编辑或删除，代表数据已最终确认。

### 1.4 日报操作权限汇总

| 角色 | 创建 | 编辑 | 删除 | 审核 | 反审 | 锁定 | 解锁 |
|------|:----:|:----:|:----:|:----:|:----:|:----:|:----:|
| 员工 | ✓ | ✓ | | | | | |
| 店长 | ✓ | ✓ | ✓ | | | | |
| 财务 | ✓ | ✓ | ✓ | ✓ | ✓ | | |
| 老板 | | | | | | ✓ | ✓ |
| 管理员 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

## 二、资金汇总

进入「资金管理 → 资金汇总」，可按时间范围和店铺查看汇总数据。

**功能：**
- 按日期范围筛选
- 按店铺筛选
- 查看各项资金指标的合计
- 导出 Excel（老板、财务可用）

## 三、系统管理（管理员专属）

以下功能仅 admin 角色可见。

### 3.1 用户管理

路径：「系统管理 → 用户管理」

**操作：**
- 新建用户：设置用户名、显示名、初始密码
- 编辑用户：修改显示名、状态（启用/停用）
- 分配角色：给用户指定一个或多个角色
- 分配店铺：指定用户可访问的店铺（影响数据范围）
- 修改密码：重置用户密码

**用户状态：**
- 启用（active）：正常使用
- 停用（disabled）：无法登录，数据保留

### 3.2 角色管理

路径：「系统管理 → 角色管理」

**操作：**
- 新建角色：设置角色编码、名称、数据范围
- 编辑角色：修改名称和数据范围
- 分配权限：勾选该角色可访问的菜单和按钮

**数据范围说明：**

| 数据范围 | 含义 |
|----------|------|
| all | 可看所有店铺的数据 |
| shop | 只能看自己被分配的店铺数据 |
| self | 只能看自己创建的数据 |

### 3.3 店铺管理

路径：「系统管理 → 店铺管理」

- 新建店铺：设置店铺名称、所属品牌
- 编辑店铺：修改名称、品牌归属

### 3.4 品牌管理

路径：「系统管理 → 品牌管理」

- 新建品牌：设置品牌名称
- 编辑品牌：修改品牌名称

### 3.5 菜单管理

路径：「系统管理 → 菜单管理」

管理系统的导航菜单结构，一般不需要修改。如需新增功能模块时使用。

## 四、常见操作流程

### 4.1 员工每日录入流程

1. 登录系统
2. 进入「资金管理 → 资金日报」
3. 点击「新建」
4. 选择店铺、日期
5. 填写营业额及各项资金数据
6. 如有凭证，上传附件
7. 点击「保存」

### 4.2 财务审核流程

1. 登录系统
2. 进入「资金管理 → 资金日报」
3. 筛选状态为「未审」的日报
4. 逐条核对数据
5. 确认无误后点击「审核」
6. 如有问题，点击日报进入编辑修改，或通知录入人修改

### 4.3 老板确认流程

1. 登录系统
2. 进入「资金管理 → 资金日报」
3. 筛选状态为「已审」的日报
4. 确认后点击「锁定」
5. 如需查看汇总，进入「资金汇总」导出 Excel

### 4.4 管理员新增员工流程

1. 进入「系统管理 → 用户管理」
2. 点击「新建」，填写用户名和初始密码
3. 保存后，点击「分配角色」，选择对应角色
4. 点击「分配店铺」，选择该员工可访问的店铺
5. 通知员工登录并修改密码

## 五、注意事项

- **密码安全**：首次登录后务必修改默认密码
- **日报时效**：建议当日录入当日数据，避免遗漏
- **锁定不可逆**：锁定后的日报只有老板可以解锁，请确认数据无误后再锁定
- **数据范围**：每个用户只能看到自己权限范围内的数据，如需扩大范围请联系管理员
- **浏览器**：推荐使用 Chrome / Edge 最新版本
