可可衣连锁女装 - 店铺记账管理系统 PRD
一、项目概述
1.1 基本信息
应用名称：可可衣连锁女装

网站类型：功能服务型（B2B管理工具）

产品类型：多店铺财务记账管理系统

核心价值：为连锁女装门店提供统一的日常记账、资金流水管理、自动对账功能，简化店长日常财务操作，实现总部与门店之间的资金流转透明化

目标用户：各连锁门店店长（主要使用者）、财务人员（查看汇总数据）

1.2 技术配置
数据库：需要数据库（暂不启用，待页面生成后启用）— 用于存储店铺信息、每日记账记录、资金流水明细、审核状态等数据

网站主语言：中文

响应式要求：适配桌面端（主要使用场景）、平板、移动端（便于店长随时查看）

二、核心功能
2.1 功能模块
功能1：店铺管理
一句话功能说明：管理所有连锁门店的基本信息

使用场景：新增门店、编辑门店信息、查看门店列表

操作流程：添加店铺 → 填写店铺代码/名称/品牌 → 保存 → 在记账时选择对应店铺

优先级：高（MVP）

功能2：资金日报（核心记账功能）
一句话功能说明：录入每日店铺资金流水，自动计算期末余额

使用场景：店长每日营业结束后录入当天各项收支数据

操作流程：

选择日期、店铺

录入各项数据：营业额、刷给公司、转/存给公司、店铺费用、交给店老板款、

系统自动计算：期末余额 = 期初余额 + 实际业绩 - 刷给公司 - 转/存给公司 - 交给店老板款 - 店铺费用

添加备注和凭证图片（可选）

提交保存（状态为"未审"）

状态有已审，未审，审1，已审状态不可更改

优先级：高（MVP）

功能3：资金汇总表
一句话功能说明：按日期范围、店铺筛选查看资金流水汇总

使用场景：店长或财务人员查看某段时间内各店铺的资金情况

操作流程：选择日期范围 → 选择店铺/品牌 → 查看表格 → 支持导出Excel

优先级：高（MVP）

功能4：审核管理
一句话功能说明：对提交的资金日报进行审核/反审操作

使用场景：财务人员或上级管理者审核店长提交的日报数据

操作流程：查看未审记录 → 核对数据 → 点击"审1"通过 或 "反审1"驳回

优先级：高（MVP）

功能5：凭证图片上传
一句话功能说明：为每笔记录上传相关凭证图片（如小票、转账截图等）

使用场景：录入数据时上传证明材料，便于后续核对

操作流程：点击"Browse…" → 选择图片 → 上传（每条记录可上传多张图片）

优先级：中（增强）

功能6：数据导出
一句话功能说明：将资金汇总表导出为Excel文件

使用场景：财务人员需要离线分析或存档

操作流程：设置筛选条件 → 点击"导出"按钮 → 下载Excel文件

优先级：中（增强）

5.5 交互动效
整体基调：克制实用，不影响操作效率

核心动效：

按钮hover：轻微背景色加深 + 阴影

表格行hover：浅灰色背景高亮当前行

状态切换：审核/反审时行背景色平滑过渡（300ms）

弹窗出现：从中心淡入 + 轻微缩放（200ms）

保存成功：绿色提示从顶部滑入（300ms），2秒后自动消失

数字变化：期末余额计算完成时数字滚动效果（可选）

动效参数规范：

过渡时长：常规交互200-300ms，状态切换300ms，提示消失2000ms

缓动函数：ease-out / cubic-bezier(0.4, 0, 0.2, 1)

hover效果：背景色变化 + 位移1-2px

表格行高亮：背景色#F5F7FA，过渡200ms

禁止：

❌ 避免过多装饰性动画，影响数据录入效率

❌ 不使用弹跳、抖动等活泼动效

✅ 所有动效必须服务于功能反馈（状态变化、操作确认）

七、补充说明
7.1 计算公式说明
系统需自动计算以下字段：

实际业绩 = 营业额 - 卡扣

期末余额 = 期初余额 + 实际业绩 - 刷给公司 - 转/存给公司 - 交给店老板款 - 店铺费用

注：期初余额为上一日的期末余额，系统自动带入

7.2 审核流程说明
店长提交日报后，状态默认为"未审"

财务或上级可进行"审1"（通过）或"反审1"（驳回）操作

已审记录不可直接修改，需先"反审1"退回

审核操作需记录操作人和时间（数据库自动生成）

7.3 数据权限说明
店长仅可查看和管理自己店铺的數據

财务人员可查看汇总数据和审核

管理员拥有全部权限（店铺管理、用户管理等）

注：用户权限系统由平台认证系统自动处理，PRD中不展开
